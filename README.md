# Aviation Accidents Data Analysis

## Project Overview
This project analyzes aviation accident data to evaluate aircraft safety and identify factors associated with serious injuries, fatalities, and aircraft damage. The aim is to support informed decisions on aircraft safety and insurance risk.

## Project Files
- **Aviation_Accidents_Cleaning.ipynb** – Data inspection, cleaning, handling missing values, and preparing the dataset.
- **Aviation_Accidents_Data_Analysis.ipynb** – Exploratory analysis, visualizations, and safety comparisons.

## Key Areas of Analysis
- Aircraft manufacturers and models
- Small versus large aircraft safety
- Serious and fatal injury rates
- Aircraft destruction rates
- Weather conditions and phases of flight

## Tools and Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.

## How to Run
1. Install the required Python libraries.
2. Run the cleaning notebook using `AviationData.csv`.
3. Save the cleaned dataset as `AviationData_Cleaned.csv`.
4. Run the analysis notebook using the cleaned dataset.

Update the CSV file paths in both notebooks to match your local directory.

## Conclusion
The project explores patterns in aviation accident severity and aircraft damage to help inform safety assessments and risk management decisions.
